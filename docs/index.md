# Pickles

Pickles is a tool for writing system specifications in structured, natural-language scenarios in Pickles, a DSL that extends Gherkin and its Given/When/Then structure, and turning them into a single model of your system's behavior. From that model you can generate test cases, and translate formal test cases back into plain-language descriptions. This tool is based on the paper [PICKLES: a Natural Language Framework for Requirement Specification and Model-Based Testing](https://www.jot.fm/issues/issue_2026_03/a25.pdf) authored by María Belén Rodríguez and Petra van den Bos.
